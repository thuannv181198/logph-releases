# Log(P)-h — bản cài đặt cho Windows

Chương trình vẽ đồ thị log(p)-h của môi chất lạnh và đồ thị không khí ẩm (I-d, t-d), tính chu
trình lạnh và trạng thái không khí. Tính chất nhiệt động lấy từ CoolProp.

Kho này chỉ chứa **bản cài đặt**. Mã nguồn không nằm ở đây.

## Tải về

Mở mục **[Releases](../../releases/latest)** và chọn một trong các file sau:

| File | Dùng khi |
|---|---|
| `Log(P)-h Free_<phiên bản>_x64-setup.exe` | Bản miễn phí |
| `Log(P)-h Free_<phiên bản>_x64-offline-setup.exe` | Bản miễn phí cho máy **không có Internet**, có sẵn WebView2 (khoảng 210 MB) |
| `Log(P)-h Pro_<phiên bản>_x64-setup.exe` | Bản Pro. Cần mã kích hoạt (licence code) do tác giả cấp |

Các file `logph-*.exe` và `latest-*.json` là để chương trình **tự cập nhật**. Bạn không cần tải
các file này.

## Cài đặt

Bản cài đặt chưa được ký số, nên lần đầu mở Windows có thể báo *"Windows protected your PC"*. Khi
đó bấm **More info**, rồi **Run anyway**.

Cài bản mới đè lên bản cũ không làm mất thiết lập, các điểm trạng thái hay giấy phép Pro.

## Cập nhật

Từ phiên bản 0.1.1, chương trình tự kiểm tra bản mới mỗi lần khởi động. Khi có bản mới, nút
**Update to …** hiện ở góc trên bên phải; bấm nút đó là chương trình tự tải và cài. Mỗi bản cập
nhật đều được kiểm tra chữ ký trước khi cài.

Nếu máy bạn đang dùng bản 0.1.0, hãy tải và cài bản mới nhất một lần. Từ đó trở đi chương trình
tự cập nhật.

*English:* Windows installers of Log(P)-h (refrigerant log(p)-h charts, humid-air charts, cycles).
Download the latest release: **Free**, **Free offline** (with WebView2 included) or **Pro** (needs
a licence code from the author). The `logph-*.exe` and `latest-*.json` files are for the
programs' automatic updates.
